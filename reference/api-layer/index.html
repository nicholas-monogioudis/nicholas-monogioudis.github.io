    Provider Abstraction

    NeuroLens abstracts the LLM provider so the same interface works across environments:
    EnvironmentProviderUsage
    DevelopmentClaude CodeDirect orchestration, pipeline development, experiments
    ProductionAnthropic APIQ&A, research synthesis, clinical summaries
    Production (alt)OpenRouterMulti-model access, cost optimization

    ​
    Interface

    from neurolens.api import get_provider

provider = get_provider("anthropic")  # or "openrouter"
response = provider.query("What are the amyloid-beta trends?", context=data_summary)
summary = provider.summarize(research_text)
    The provider is selected by configuration, not code changes.
